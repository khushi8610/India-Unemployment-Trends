# India-Unemployment-Trends
# 📊 Unemployment Analysis with Python

## 📌 Project Overview

This project performs an Exploratory Data Analysis (EDA) on India's unemployment data using Python. The primary objective is to analyze unemployment trends across different states and over time, with a special focus on understanding the impact of the COVID-19 pandemic on employment.

The project uses data preprocessing, statistical analysis, and visualizations to uncover meaningful insights into unemployment patterns across India.

---

## 🎯 Objectives

- Analyze unemployment trends across Indian states.
- Study monthly unemployment patterns.
- Compare unemployment rates before and after COVID-19.
- Identify states with the highest average unemployment.
- Explore the relationship between unemployment, employment, and labour participation rate.
- Create informative visualizations for better understanding of the dataset.

---

## 📂 Dataset

**Dataset:** Unemployment in India

The dataset contains unemployment statistics collected from different states and union territories across India.

### Dataset Features

- Region
- Date
- Frequency
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area (Urban/Rural)

## 🔍 Key Insights

- Unemployment rates vary significantly across different Indian states.
- Certain states consistently recorded higher unemployment rates than others.
- Monthly unemployment trends show noticeable fluctuations over time.
- Urban and Rural areas exhibit different unemployment patterns.
- A strong relationship exists between employment-related indicators.
- The COVID-19 pandemic caused a significant increase in unemployment across India.

---

## 🦠 COVID-19 Analysis

The dataset was divided into:

- **Pre-COVID:** Before March 2020
- **Post-COVID:** March 2020 onwards

The comparison shows that unemployment rates increased considerably after the onset of the COVID-19 pandemic due to lockdowns and reduced economic activity.
